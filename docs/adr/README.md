# Architecture Decision Records

This folder records the significant technical decisions of the project: the context, the options considered, the decision and its consequences.

One decision per file, numbered in order (`NNNN-short-title.md`). Records are never deleted: when a decision changes, the old record is marked as superseded and a new one explains why.

**Statuses:** Proposed · Accepted · Superseded by ADR-NNNN · Rejected

| ADR | Title | Status |
|---|---|---|
| [0001](0001-project-domain-steam.md) | Project data domain: Steam ecosystem | Superseded by ADR-0003 |
| [0002](0002-repository-language.md) | Repository language | Accepted |
| [0003](0003-domain-change-vehicle-energy-mx.md) | Domain change: vehicles and energy in Mexico | Accepted |

## Template

```markdown
# ADR-NNNN: Short title

- **Date:** YYYY-MM-DD
- **Status:** Proposed | Accepted | Superseded by ADR-NNNN | Rejected

## Context
## Options considered
## Decision
## Rationale
## Consequences
```
